================================================================
AUTHENTICATION
================================================================

Semua endpoint PROTECTED memerlukan header:
  Authorization: Bearer <access_token>

Token disimpan di:
- access_token → localStorage atau memory (httpOnly tidak bisa JS)
- refresh_token → dikirim via httpOnly Cookie secara otomatis oleh server

  },

Catatan:
- Server juga set httpOnly cookie: refresh_token
- access_token valid 15 menit
- refresh_token valid 7 hari
- Setelah 5 gagal login: locked 15 menit
- Implementasi reCAPTCHA v2 di frontend (site_key dari env)
- Jika RECAPTCHA_SECRET_KEY kosong di backend, verifikasi dilewati (dev mode)

Response 401: Kredensial salah
Response 403: Akun dinonaktifkan
Response 429: Rate limit / akun terkunci

================================================================
AXIOS INTERCEPTOR SETUP
================================================================

// lib/axios.ts
import axios from 'axios'

const api = axios.create({
  baseURL: process.env.NEXT_PUBLIC_API_URL || 'http://localhost:3000',
  withCredentials: true,  // penting untuk refresh_token cookie
})

// Request interceptor: tambah access token
api.interceptors.request.use((config) => {
  const token = useAuthStore.getState().accessToken
  if (token) config.headers.Authorization = `Bearer ${token}`
  return config
})

// Response interceptor: auto refresh token jika 401
api.interceptors.response.use(
  (res) => res,
  async (error) => {
    const original = error.config
    if (error.response?.status === 401 && !original._retry) {
      original._retry = true
      try {
        const { data } = await axios.post('/api/auth/refresh-token',
          {}, { withCredentials: true }
        )
        const newToken = data.data.access_token
        useAuthStore.getState().setToken(newToken)
        original.headers.Authorization = `Bearer ${newToken}`
        return api(original)
      } catch {
        useAuthStore.getState().logout()
        window.location.href = '/login'
      }
    }
    return Promise.reject(error)
  }
)

export default api

================================================================
CATATAN PENTING
================================================================

1. Salary format: tampilkan sebagai Rupiah
   Intl.NumberFormat('id-ID', { style: 'currency', currency: 'IDR' }).format(salary)

2. Date format: gunakan id-ID locale
   new Date(date).toLocaleDateString('id-ID')

3. Profile photo URL: gabungkan base URL + file_path
   `${process.env.NEXT_PUBLIC_API_URL}${employee.profile_photo}`

4. Jika profile_photo null: tampilkan avatar inisial nama

5. Import template download:
   GET http://localhost:3000/uploads langsung serve static file
   atau buat endpoint di frontend yang serve template dari public/

6. reCAPTCHA: gunakan react-google-recaptcha package
   Site key dari NEXT_PUBLIC_RECAPTCHA_SITE_KEY
   Token kirim ke backend dalam field recaptcha_token

7. Untuk development tanpa reCAPTCHA aktif, cukup kirim:
   "recaptcha_token": "dev-bypass"
   Backend akan skip jika secret key tidak dikonfigurasi.
